# Hokena Care — Heal in India

> **Premier Surgery & Medical Healthcare Pathway Web Application**  
> Built with React 19, Vite, Tailwind CSS v4, Lucide Icons, and AOS animations with the official Hokena Care Orange & Medical Red theme.

---

## 🎨 Theme & Design Tokens

- **Primary Brand Orange**: `#FF6B00` / `#FF7A00`
- **Medical Red Accent**: `#F44236` (matching the Caduceus and Medical Cross)
- **Deep Navy Ink**: `#0B1220`
- **Warm Medical Mist**: `#FFFBF7`
- **Typography**: Plus Jakarta Sans (Display Headings) & Inter (Body)

---

## 🖥️ Included High-Fidelity Screens

1. **Screen 01: Home Landing Page (`/`)**
   - Dynamic typewriter hero banner, quick services strip, 24/7 helpline, surgical specialties grid, 3-step patient journey, doctor showcase, and floating care navigator card.
2. **Screen 02: Surgical Treatments (`/treatments`)**
   - Interactive category filters (Orthopedics, Laparoscopic, Cardiology, Urology, Oncology, Ophthalmology), technology specs, and hospital stay metrics.
3. **Screen 03: Specialist Doctors (`/doctors`)**
   - Comprehensive surgeon directory with multi-specialty filters, experience badges, hospital affiliations, patient ratings, and appointment booking.
4. **Screen 04: Health Packages (`/packages`)**
   - NABL-accredited health checkup packages and pre-surgery clearance panels with home sample pickup and digital report turnaround.
5. **Screen 05: Heal in India Concierge (`/heal-in-india`)**
   - Dedicated medical tourism screen for international & outstation patients with visa facilitation, airport concierge, language interpreters, and instant inquiry.
6. **Screen 06: Contact & Second Opinion (`/contact`)**
   - Interactive clinical case review form, hospital network location map, 24/7 hotline cards, and WhatsApp direct connection.
7. **Screen 07: Figma Screen Showcase (`/screens`)**
   - Interactive Figma-style screen frame viewer with device viewport toggling (Desktop 1440px, Tablet 768px, Mobile 390px), color token swatches with click-to-copy hex, and typography scale inspector.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Vijay2r24/hokena-care.git

# Navigate to project directory
cd hokena-care

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application runs on `http://localhost:5174/` by default.
